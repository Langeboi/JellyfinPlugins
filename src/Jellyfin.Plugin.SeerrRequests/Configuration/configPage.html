Seerr Requests

Connect this Jellyfin server to your Seerr instance so household members can search for and request new movies and shows without leaving Jellyfin. Colours are read from whichever theme you are running, so the tabs blend into any skin.

Connection

The base URL of your Seerr / Jellyseerr / Overseerr instance, no trailing slash. Jellyfin reaches it server-side, so a LAN address is fine.
An admin-level API key from Seerr. Stored server-side only, never sent to the browser. Requests are attributed to each household member's own Seerr account, provided they have signed into Seerr with their Jellyfin login at least once.

Appearance

This settings page is always English.
Backgrounds and overlays always follow your theme. This only decides the colour of the request buttons and highlights: off keeps Seerr's own indigo, which makes the tabs read as "the Seerr part"; on makes them match the rest of Jellyfin.
Search, trending, and browse by genre, with a request button on every poster.
When everything requested through Seerr actually arrives. Films show the streaming date, never the cinema premiere.
Cosmetic only — the library cards themselves stay. The whole row can also be turned off in Jellyfin's own display preferences.
Comma-separated ISO 639-1 language codes. Browse rows, trending and the upcoming hero hide titles whose original language is in this list. Search is never filtered. Empty by default.
