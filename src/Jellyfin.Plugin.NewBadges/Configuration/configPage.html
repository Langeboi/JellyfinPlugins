New Badges

Home-page and library upgrades that Jellyfin's own CSS cannot reach. Everything below is optional — switch off what you do not want. Colours are read from whichever theme you are running, so nothing here assumes a particular skin.

General

This settings page is always English.

Home page

What the other users on this server have actually been watching, ranked by how many different people watched it. Requires the Playback Reporting plugin — without it there is no cross-user watch data to rank, and your normal Next Up row is left alone.
A show you have caught up on keeps its place in the row with its next unwatched episode, instead of vanishing until you start it.
Hovering a card for three seconds starts a muted preview from where you left off, and clicking resumes straight away instead of opening the details page first. Desktop only; the preview is a direct stream, so it is skipped for anything your browser cannot decode.
Desktop only.
