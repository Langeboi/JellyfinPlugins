Hero Bar

Rotating featured-content hero at the top of the home page, built in-flow so it never overlaps or clashes with other sections. Its colours are read from whichever theme you are running, so it blends into any skin without configuration.

This settings page is always English.

Mixes in what other users on this server have been watching recently, alongside recently added items. Requires the Playback Reporting plugin — without it there is no cross-user watch data, and the hero quietly falls back to recently added only.
